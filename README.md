## Description 
> PrestoPaws is an app dedicated to helping new cat owners find quality food, toys, etc. for their cats from offical businesses using feedback from owners who have previously bought and used the item(s).
> The motivation for this app is to help cat owners maintain and care for their cats.
>

## App Functions
1. Customer (the user with the customer role):
    1. Create/modify customer profile - App will provide a button which leads to a profile setup page.
    2. View available items - App will display a list of items that can be purchased, as well as their ratings/reviews.
    3. Purchase items - User can input payment/shipping info and purchase listed items.
    4. Create reviews - User can leave a review and a rating for items purchased.
2. Provider (the user with the provider role):
    1. Create/modify/remove provider profile - Businesses can create, modify, and remove a profile representing themselves; these profiles should be kept to one profile per business.
    2. Create services - Providers can create pages that display a product, a description of the product, a price for the product, and other information about the product (item dimensions, how-to-use, etc.) 
    3. View customer statistics - Providers can view in their profile how many of which products have sold as well as view the most recent reviews left on products.
    4. Reply to reviews - Providers can, in their profile, click on a review to be sent to the page where the review was left. On the page, they can reply to the review and publish the response.
